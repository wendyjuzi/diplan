摘要
现有 LLM Agent 在短程任务中常表现出较强的逐步推理能力，但在长程任务中容易出现
早期短视承诺、错误累积、约束遗忘和行动轨迹崩塌。近期工作从规划中心视角指出，step-wise
reasoning 本质上接近局部贪心决策；即便扩大 beam width，也不能从根本上避免早期局部最
优动作导致的全局失败。受此启发，本报告提出一个全新的 Diffusion-based Plan-Centric
框架，用于长程工具调用、网页操作、知识图谱推理和 embodied/text-game 任务。与基于显
式树搜索的 MCTS-lookahead 不同，本文设计的 DiPLaN 将计划表示为条件轨迹分布，利用
扩散模型在计划空间中生成多样化、全局一致的候选计划，并通过价值引导、可行性投影、约
束验证和 receding-horizon 执行机制实现面向未来的行动选择。本报告给出完整问题定义、模
型结构、训练流程、推理算法、理论分析框架、实验设计、实施路线和风险控制，目标是形成
一个可执行、可投稿、原创性较强的研究方案。
1 研究背景与核心问题
1.1 长程 Agent 的根本困难：reasoning 不等于 planning
长程任务与普通问答或短程推理不同。Agent 不仅要生成看似合理的下一步，还要维持跨多
个阶段的目标一致性、约束一致性、状态记忆、工具依赖和错误恢复能力。在工具调用、网页操
作、知识图谱多跳推理、ALFWorld/ScienceWorld 等环境中，早期一个局部看似合理的动作可能
把 Agent 带入不可恢复的错误区域。
近期论文 Why Reasoning Fails to Plan: A Planning-Centric Analysis of Long-Horizon Deci-
sionMakinginLLMAgents明确提出：LLM的step-by-stepreasoning可以被抽象为一种step-wise
greedy policy，即每一步根据局部评分选择动作，而不是根据未来累计价值选择动作。该文证明
step-wise greedy policy 在长程任务中可能任意次优，并指出 beam search 只是扩大局部搜索宽
度，仍不能避免最优前缀被早期剪枝的问题。论文还提出 FLARE 作为显式 lookahead、backward
value propagation 和 limited commitment 的最小实现，用于证明规划机制的重要性。
这一诊断对我们提出新框架非常关键：如果长程失败来自“局部推理范式”本身，那么单纯增
加 CoT、self-reflection、beam width 或模型规模并不足够。真正需要的是一种计划中心机制：它
必须能在行动前显式构造多个可能未来，并让远期结果影响早期动作。
1.2 为什么不直接沿用 MCTS
MCTS 是一种自然的显式前瞻机制，但如果研究目标是提出具有较强原创性的 Agent 规划框
架，直接沿用 MCTS 有三个限制。
第一，MCTS是在线树搜索，计算成本随分支数和深度快速增长。在真实tool-use或webtask
中，状态与动作空间通常巨大且语义复杂，树搜索很容易被无效分支消耗预算。
第二，MCTS 的探索通常依赖离散树结构。很多 LLM Agent 的计划不是标准离散动作树，而
是由自然语言子目标、工具调用、参数选择、约束满足和执行检查共同组成的混合对象。将其强
行离散成树，容易丢失计划之间的语义邻近性。
第三，MCTS主要是在线搜索机制。它能在单个实例上搜索较好轨迹，但不天然提供跨任务的
计划分布学习能力。相比之下，扩散模型可以学习“成功计划长什么样”，并在新任务中以amortized
planning 的方式快速生成候选计划。

2 研究目标与总体思路
2.1 研究目标
本方案旨在构建一个面向长程任务的 Diffusion-based plan-centric Agent 框架，满足以下目
标：
1. 全局规划性：在执行动作前生成多步候选计划，而非只选择下一步动作。
2. 多模态未来覆盖：能够生成多条语义不同、策略不同的候选计划，覆盖不同可能路径。
3. 价值感知：计划生成不只是模仿历史轨迹，还要被任务成功、长期回报和约束满足引导。
4. 有限承诺：不一次性执行完整计划，而是在每轮执行一个动作或一个子目标后重新规划。
5. 可执行性：计划必须能映射到真实 action/tool call，包括工具名、参数、前置条件和后置检
查。
6. 可审计性：计划应具有结构化表示，方便诊断早期错误、约束违规和执行偏离。
2.2 框架命名：DiPLaN
本文将提出的框架命名为DiPLaN:Diffusion Planner for Long-Horizon Agentic Rea-
soning。其核心不是让扩散模型直接输出最终答案，而是让扩散模型生成计划轨迹，再由执行器
完成动作或工具调用。

• 低层动作强依赖环境细节，跨任务迁移差；

7 训练方案
7.1 数据来源
DiPLaN 需要计划轨迹数据。可行数据来源包括：
1. 专家或规则轨迹：KGQA 中的 oracle paths、ALFWorld 中的成功 action sequences、工具任

12 原创性分析
相较于已有 plan-then-act 或 MCTS-lookahead 方法，DiPLaN 的原创性体现在以下方面。
1. 计划分布而非单一路径：现有方法常搜索或生成一条计划，DiPLaN 学习多模态计划分布。
2. amortized planning：通过离线学习成功计划轨迹，减少每个新任务从零搜索的成本。
3. value-guided denoising：不是先生成再被动打分，而是在去噪过程中引入价值和约束引导。
4. latent structured plan space：不是直接扩散自然语言，也不是直接扩散低层动作，而是
在可解码的结构化计划潜空间中生成。
5. 机制级诊断：以 Trap@1、First-Error Step、Recovery、Plan-Execution Consistency 等指标
分析长程规划行为，而不只报告最终成功率。

15 结论
本报告提出了一个完整、可执行且具有较强原创性的研究方向：用扩散模型构建 plan-centric
长程Agent推理框架。与step-wisereasoning相比，该框架显式生成未来计划；与MCTS-lookahead
相比，它学习条件计划分布并支持 amortized planning；与普通 diffusion decision-making 相比，
它强调结构化计划、工具可执行性、约束验证和 receding-horizon 执行。
最适合的研究切入点是：先在 KGQA 或 ALFWorld 上验证 diffusion planner 能否降低早期
短视错误、推迟首错位置并提高恢复能力；随后扩展到工具调用和网页任务。若实验结果支持该
机制，该方向可以形成一篇围绕“Generative Planning for Long-Horizon LLM Agents”的较有潜
力论文。
